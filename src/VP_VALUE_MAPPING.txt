VP VALUE MAPPING
================

RTC:
- Date text = 0x1500, 16 bytes / 8 words
- Time text = 0x1510, 16 bytes / 8 words

Slots:
- Slot icon base = 0x1000
- Slot 1 = 0x1000
- Slot 40 = 0x1027
- Slot confirm OK = 0x1028
- Slot cancel = 0x1029
- Selected count = 0x1030
- Slot state values: Available 0x0000, Selected 0x0001; inactive/taken values
  are defined by SLOT_NA / SLOT_TAKEN in main.cpp.
- Home Dashboard Pages 2 and 3: tap an available slot to select it; tap the
  same selected slot again to deselect it; tap a different available slot to
  move the single selection.
- Slot touch events are routed by VP address; a returned value of 0x0000 is
  valid and must not be treated as a missing touch.
- The active-high safety limit switch on GPIO34 clears temporary selection
  and returns the interface to the Locked Screen.

Current Log:
- Base = 0x1050
- Step = 0x50
- Visible cards: Page 1 = 6, Page 2/3 = 4
- Key Name offset = 0x00, 16 bytes / 8 words
- Borrower Name offset = 0x08, 32 bytes / 16 words
- Key Number offset = 0x18, 16 bytes / 8 words
- Time offset = 0x20, 24 bytes / 12 words
- Status Icon offset = 0x2C
- Status values: Empty 0x0000, Borrowed 0x0004, Returned 0x0005
- Current-day cards are restored from /daily/YYYY-MM-DD/transactions.csv using
  the RTC date at startup and when the date changes. Up to 40 newest events for
  the active date are held for display; the daily archive remains on SD.
- Cards display newest-first: card 1 is the latest event. Scrolling down moves
  toward older events; newly logged events return the view to card 1.

Transaction Log:
- Base = 0x3000
- Step = 0x50
- Visible rows = 11
- Key No offset = 0x00, 16 bytes / 8 words
- Borrower Name offset = 0x08, 32 bytes / 16 words
- Key Name offset = 0x18, 32 bytes / 16 words
- Borrowed Time offset = 0x28, 16 bytes / 8 words
- Returned Time offset = 0x30, 16 bytes / 8 words
- User offset = 0x38, 32 bytes / 16 words
- Rows display newest-first: row 1 is the latest transaction. Scroll controls
  browse toward newer or older records; selecting an export date is preserved
  while the transaction view order changes.

- Fingerprint ID offset = 0x18, 16 bytes / 8 words

Download icon:
- VP = 0x34E0
- 0x0000 Idle
- 0x0001 USB checking
- 0x0002 USB connected
- 0x0003 Downloading
- 0x0004 Success
- 0x0005 USB not found
- 0x0006 Failed
MCP23017 slot output level:
- LOCK_ACTIVE_LEVEL = HIGH = unlock/active
- LOCK_INACTIVE_LEVEL = LOW = lock/inactive

Limit switch GPIO:
- LIMIT_SWITCH_PIN = GPIO34
- Active level = HIGH
- No DWIN VP needed
- Wire active HIGH: switch to 3.3V, external 10k pulldown to GND.


Display Idle / Backlight Control:
- DWIN_BACKLIGHT_VP = 0x0082
- DWIN_BACKLIGHT_FULL = 100
- DWIN_BACKLIGHT_OFF = 0
- DISPLAY_IDLE_TIMEOUT_MS = 30000UL by default
- Optional wake touch VP = 0x13F0, value 0x0001
- VP 0x0082 is ESP32-to-DWIN backlight control only; it does not tell ESP32 that the screen was touched.
- To wake from a blank-area touch, add a DWIN Return Key Code / Basic Touch object that sends VP 0x13F0.


Admin authentication:
- Admin Login Page = 5; Admin Dashboard = 7.
- Page 7 and admin-only pages require a successful PIN login.
- Default PIN = 3030; saved PIN is stored in ESP32 Preferences.


Page 27 Update Password VP Map
------------------------------
- Old PIN text       = 0x3B00, 8 bytes / 4 words
- New PIN text       = 0x3B10, 8 bytes / 4 words
- Confirm PIN text   = 0x3B20, 8 bytes / 4 words
- Old PIN button     = 0x3B30, value 0x0001
- New PIN button     = 0x3B31, value 0x0001
- Confirm PIN button = 0x3B32, value 0x0001
- OK / Save button   = 0x3B33, value 0x0001
- Back button        = 0x3B34, value 0x0001
- Status text        = 0x3B40, 32 bytes / 16 words
- Status icon        = 0x3B60
  - 0x0000 Idle
  - 0x0001 Editing
  - 0x0002 Saved
  - 0x0003 Error

Storage hardware:
- One SD card on SPI chip select GPIO14.
- CH376S USB host: SPI chip select GPIO25, active-low interrupt GPIO35.
- GPIO35 is input-only and has no internal pull-up; verify the CH376S module
  provides a suitable INT pull-up or install an external pull-up compatible
  with the module logic voltage.
- Daily archives: /daily/YYYY-MM-DD/
- Monthly archives: /monthly/YYYY-MM/
- Daily and monthly records are mirrored on this same card.
- The selected-date Download button exports non-empty daily CSVs to the USB
  root using FAT 8.3 filenames YYMMDDA.CSV (accounts), YYMMDDK.CSV (keys),
  YYMMDDT.CSV (transactions), and YYMMDDR.CSV (returns).
- Download status 0x0004 reports that one or more archive files were exported
  and their resulting sizes matched the SD sources; physical verification is
  still required.

Updated behavior:
- Registered RFID key returns are scanned only on Home Dashboard Pages 2/3.
- Slot occupancy is persisted in ESP32 Preferences.
- Slot outputs are timed and relocked after borrowing or returning.
- Home Dashboard slot selection toggles off on a repeated tap; a different
  available slot replaces the previous selection on both Pages 2 and 3.
- Dashboard slot/confirm input is ignored while the safety limit switch is
  active; stale selections are cleared on page transitions.
- See FEATURES_FLOW.txt for complete hardware, storage layout, and user flows.
